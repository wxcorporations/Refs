

Todos aceitam atalho `ng g ...`.[](https://angular.io/cli/generate)​

- `ng generate component <nome>` / `ng g c <nome>`  
    Gera um componente (TS + HTML + CSS + spec).[](https://dev.to/shreyash_sitapara/top-10-angular-cli-commands-you-should-know-3p34)​
    
- `ng generate service <nome>` / `ng g s <nome>`  
    Gera um service injetável para lógica de negócio / chamadas HTTP.[](https://www.tutorialspoint.com/angular/angular-cli.htm)​
    
- `ng generate module <nome>` / `ng g m <nome>`  
    Gera um módulo (útil ainda em apps híbridas, libs, etc.).[](https://dev.to/shreyash_sitapara/top-10-angular-cli-commands-you-should-know-3p34)​
    
- `ng generate directive <nome>` / `ng g d <nome>`  
    Cria uma diretiva customizada.[](https://angular.io/cli/generate)​
    
- `ng generate pipe <nome>` / `ng g p <nome>`  
    Cria um pipe customizado.[](https://www.tutorialspoint.com/angular/angular-cli.htm)​
    
- `ng generate guard <nome>` / `ng g guard <nome>`  
    Cria um guard de rota (CanActivate etc.).[](https://www.digitalocean.com/community/tutorials/angular-angular-cli-reference)​
    
- `ng generate class <nome>` / `ng g cl <nome>`  
    Cria uma classe simples TS.[](https://www.digitalocean.com/community/tutorials/angular-angular-cli-reference)​
    
- `ng generate interface <nome>` / `ng g i <nome>`  
    Cria uma interface TS.[](https://www.digitalocean.com/community/tutorials/angular-angular-cli-reference)​
    
- `ng generate enum <nome>` / `ng g enum <nome>`  
    Cria um enum TS.[](https://www.tutorialspoint.com/angular/angular-cli.htm)​
