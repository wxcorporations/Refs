# Padrões de nomeçlatura e composição

## BEM

É um padrão de nomeclatura que visa dividir o elemento em 3 partes.

- bloco
  
  - Toda parte de uma pagina que poderia ser reutilizada em outros pontos - transformado em um componente.

- elemento
  
  - Elemento pertencente ao bloco

- modificador
  
  - Esta relacionando ao estado do bloco|elemento tipo botão pode estar **desativado, ativo, destacado, pulsante**  todos eles são estado e modificadores já que  em cada caso tera uma aparencia diferente.
